This page drills the ten memory-item procedures the A330P FCOM itself marks with its own [MEM] convention, every one of them visually verified against the rendered FCOM or QRH page. Cross-checked 2026-09-01 against the A330 Student Oral Exam Learning Objectives Rev 7 (04/06/23) and Ryan's own memory-items doc: the FCOM's ten [MEM] procedures stand as drill scope.

One training-document conflict was found and resolved in the FCOM's favor: LO Rev 7 and the old personal doc teach LOSS OF BRAKING park brake as "SHORT & SUCCESSIVE APPLICATIONS" and a merged "ANTI-SKID & NWS ... ORDER OFF" line, while FCOM R17 prints "PARK BRAKE ... USE" with the short-successive-applications guidance as an unboxed note, and "A/SKID OFF ... ORDER" as its own boxed line. This page drills the current FCOM wording.

13 lines in the legacy study doc are now wrong; see memory_items_CROSSCHECK.md in the project for the relearn list.

The FCOM and the QRH win every conflict with this page, every time. The manual is the authority. This page is uncontrolled and is not a source document.

Two facts to carry with you:

  • TCAS CAUTION (Traffic Advisory) has one line, and the FCOM prints it unboxed. It is drilled here exactly as printed, without a box.
  • The box on FCOM Smoke / Fumes (pdf page 3164) is an At-ANY-TIME block, not a memory item. Smoke / Fumes is therefore deliberately absent from this drill.
